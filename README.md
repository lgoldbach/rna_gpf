## A simple API for RNA Genotype-Phenotype map generation, analysis and evolutionary simulation

This repo contains functionalities for mapping RNA genotypes to secondary
structure under different base-pairing rules, the generation and analysis of
RNA GP maps and evolutionary simulations of fitness landscapes built on top
of these GP maps. 
It mainly serves as an API for github.com/lgoldbach/altRNA_navigability_paper 
which is the code used for the research article "The promiscuity and degeneracy 
of ten unique RNA base-pairing rules can determine the success of adaptive RNA 
evolution" by Goldbach, Martin, Wagner 2026 (https://doi.org/10.1371/journal.pcbi.1014914).
